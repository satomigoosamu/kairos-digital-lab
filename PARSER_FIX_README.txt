Kairos Digital Lab 題庫解析修復 — 覆蓋檔案說明

這是局部覆蓋 ZIP，不是完整專案。解壓後，把 src 與 tests 依原路徑合併到 GitHub 專案根目錄；不要刪除其他原有檔案，也不要多包一層資料夾。
新增 pdfParserCore.js 必須一併上傳，不能只換 pdfParser.js。

修改紀錄
1. 分離 PDF 讀取與純解析核心，原有匯出介面保持相容。
2. 根據每頁欄頭定位五欄，避免固定答案欄寬吃入修訂文字。
3. 優先使用實際表格橫線定位題列；無線條時才使用相鄰題號中點。
4. 排除被儲存格裁切隱藏的文字基線，避免溢出選項污染下一題。
5. 修訂題目與修訂答案優先；有修訂題目但缺修訂答案時排除並提示，不沿用舊答案猜測。
6. 刪除／作廢列不進入測驗；缺號、重號、解析失敗、刪除列分開診斷。
7. 選項支援 1–9、A–I、圈號與全形格式；不再截斷第五選項以後的內容。
8. 空白答案、超界答案、選項缺標號或空選項不再默認第一項或強制截到最後一項。
9. 文字匯入的獨立答案表不再被誤當新題列；分行選項不再誤切題。
10. 沿用既有匯入提示區顯示異常，補足選項標籤 A–I，移除缺號提示中過度保證的文字。

原有版面、配色、考試流程、計分、儲存、其他模組與部署設定未重設。
package.json、Cloudflare/Vite 設定、worker CDN 位址未修改。沒有新增正式環境套件需求。

測試
Node.js 20 以上，在專案根目錄執行：
node --test tests/pdf-parser.test.mjs
正常建置使用原流程：npm install，接著 npm run build。

選用瀏覽器整合測試需要自行安裝 Playwright 與瀏覽器（不是正式站新增需求）。
先啟動 npm run dev，再執行 node tests/pdf-browser.spec.mjs。
可用 BASE_URL 指定本機開發網址，BROWSER_EXE 指定既有瀏覽器執行檔。
此測試使用本機 worker 替身以避免 CDN 波動，未驗證正式 CDN 可用性。

測試只使用人工合成資料。ZIP 不含客戶 PDF、真實題目、衍生 JSON、私人稽核腳本、測試截圖、node_modules 或 dist。
不要把原始 PDF 或本機擷取結果加入公開 repo / 部署。本次未 push、未部署。

適用界限
支援有文字層的表格及既有純文字格式；非 OCR。
沒有題號的跨頁續文不自動拼接，會提示人工確認；無邊框且不等高的複雜列、旋轉／直排、非矩形裁切仍需人工檢查。
只有答案且沒有完整題目的修訂、部分補充而非完整替換的修訂，不應未經人工核對直接使用。
請先在本機或私人測試環境驗證，再由你自行決定 GitHub 更新與 Cloudflare 部署時機。
